# PowerApps Ticketing System

A complete Ticket Management System built using Microsoft Power Apps, Dataverse, and Power Automate.

## Features

- Employee ticket submission
- Support user dashboard
- Ticket assignment workflow
- SLA tracking and SLA status
- Open / Closed / Assigned ticket management
- Role-based ticket views
- Automated email notifications
- Excel report generation
- Power Automate integrations
- Dataverse backend
- Attachment/File support
- Filtering and reporting options

## Technologies Used

- Microsoft Power Apps
- Microsoft Dataverse
- Power Automate
- Excel Online
- SharePoint / OneDrive
- Power Fx

## Functionalities

### Employee Side
- Create tickets
- Upload attachments/files
- Track ticket status
- View submitted tickets

### Support User Side
- Assign tickets
- Update ticket status
- SLA monitoring
- Close tickets
- Generate reports

### Reporting
- Export filtered ticket reports to Excel
- Filter by:
  - Status
  - Assigned User
  - Date Range

## SLA Logic

- SLA Due Date tracking
- SLA Status:
  - Within SLA
  - Completed Within SLA
  - Completed After SLA

## Automation

Power Automate flows are used for:
- Email notifications
- Report generation
- Excel export
- Workflow automation
